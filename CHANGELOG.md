# Changelog

## 1.0.0 — Initial portable release (planned)

- Floating Glass Shelf and Floating Island layouts.
- Recent file scanning, thumbnails, favourites and image filtering.
- Native drag-and-drop and file context actions.
- Global shortcut, notification-area controls and optional Windows startup.
- Dark, light and system appearance.

This version label is for public distribution; earlier internal development versions used v9.x labels.
